## Задача проект

Создать универсальный сервис для пользователя, предлагающий прдсказание стоимости различных финансовых активов на 15 дней вперёд от текущей даты.

Данные, которые были использованы для исследования, хранятся по ссылке [https://disk.yandex.ru/d/tyiqisXD8hxZQQ](https://disk.yandex.ru/d/tyiqisXD8hxZQQ)

## Развёрнутые сервисы проекта

После запуска проекта будут доступны следующие сервисы:

- http://ip:9001   # web mninio
- - На сервисе создан бакет S3 для хранения обученных моделей и логов обучения от MLflow
- http://ip:7080/browser/  # Коносль PostreSQL, ДБ доступна по порту 5432
- - Для хранения скаченных датасетов была выбрана и развёрнута PostgreSQL
- http://ip:8000/docs  # Fast API
- - Основной back-end сервис для принятия запросов от front-end (Streamlit). На его мощностях происходит предсказание с использованием обученных моделей
- http://ip:8501 # Streamlit
- - Основной интерфейс для взаимодействия с пользователями и получения от них запросов на предсказание
- http://ip:5050 # MLflow
- - Сресив для логировани и просмотров результатов ранов обучения всех моделей
- http://ip:8080 # Airflow
- - Серсив для запуска циклов по сбору данных и обучению моделей
- http://ip:8888 # Jupyter notebook
- - сервис для проведения основных ислследований моделей для предсказания стоимостей различных активов

## Запуск проекта 

Для разработки и поднятия проекта используется Ubuntu 24.04 LTS с Python 3.12.3

Запуск проека:
- Выдача прав для выполнения скрипта ```chmod +x start_all.sh```
- - По мере запуска понадобится дополнительно создать папки дял airflow ```mkdir logs dags plugins``` в папке ```Airflow-services``` и выдать права ```sudo chown -R 50000:$USER dags logs plugins```
- Запуск скрипта автозапуска из папки проекта ```./start_all.sh```
- Готово

## Использование проекат

Для использования проекта нужно перейти по http://ip:8501 и выбрать раздел "Прогноз стоимости активов". Сейчас на выбор предсказание по 4 сферам финаносвых активов:
- Криптовалюты
- Нефтеные фьючерсы
- Акции метталургических компаний
- Акции нефтедобывающих компаний
- Спотовы цена на драгоценные металы

Текущая реализация проекта предоставляет предсказание стоимости актива на следующие 15 дней от максимальной даты, хранящейся в Postgres.
