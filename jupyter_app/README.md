# Сервис для проведения исследований и разработки моделей для предсказания стомости активов


Данный серси был создан для проведения EDA, и исследовать, в каких сферах модели справляются с задачей прогнозирования лучше всего, и построить как классические, так и ML-модели, способные предсказывать будущие значения цен на основе исторических данных.

## Структура исследовательсокй работы "Research_predict_of_financial_assets"

Работа строится по следующей схеме:

**Каждый блок работы вынесен в отдельную тетрадку для удобства просмотра данных и удобства корректировки работы в целом**

- Создана 1 тетрадка (Part 0. Research results.ipynb) в которой будут сделаны основные выводы по проведенным исследованиям в каждом блоке
- В каждом блоке исследований будет оглавление, с краткой информацией о проводимых в данном блоке исследований и минимальным кол-вом текста.

**Файловая структура исследования:**

- Загрузка и предобработка данных (Part 1. Load data.ipynb). Ссылка -> Загрузка данных
- Исследовательский анализ данных (EDA). Ссылка -> Перобработка и ислледование данных
- Создание baselina модели. Ссылка -> baseline
- Прогнозирование с помощью ML-моделей. Ссылка -> ML_models
- Итоговое тестирование лучших моделей. Ccылка -> Final test

##  Описание данных, взятых за основу исследования

Основное исслендование будет проводиться на 10 датасетах с временными рядами различных финансовых активов, а именно:

- Криптовалюта
- Нефтеные фьючерсы
- Акции метталургических компаний
- Акции нефтедобывающих компаний
- Спотовы цена на драгоценные металы
