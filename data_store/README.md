# Сервис для развёртывания БД в PostgreSQL и бакета S3 в MinIO

Данный сервис запускает основное хранилище данных (PostgreSQL и бакет s3)


## Структура сервиса

```
.
├── docker-compose.yml
├── .env
└── README.md

```

Описание структур: 
- docker-compose.yml- файлы для сборки сервиса. 
- .env - файл с секретами. Логины и пароли для входа/коннекта к PostgreSQL, pgAdmin, MinIO

## Задача сервиса data_store

Хранение выборок с yfinance (PostreSQL), логово обучения моделей от Mlflow и самих обученных моеделй(S3 бакет)
